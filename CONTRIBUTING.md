# Contributing to LunAIR

Thank you for your interest in contributing to LunAIR!

## Development Guidelines

1. **Branches**: Use `feat/`, `fix/`, `chore/`, or `docs/`.
2. **Commit Convention**: Follow Conventional Commits (`feat:`, `fix:`, `chore:`, etc.).
3. **No Secrets**: Never commit `.env`, live API tokens, or real credentials. Always use environment variables and mock providers in tests.
4. **Testing**: Ensure all lint checks and test suites pass before submitting pull requests.
